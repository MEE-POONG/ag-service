💡 เพียงเพิ่มโค้ด 2-3 บรรทัดในเว็บไซต์ของคุณก็ใช้งานได้ทันที!
🔐 สำคัญ: ผู้ใช้ต้องลงทะเบียนหรือเข้าสู่ระบบก่อนใช้งานแชท (ระบบจะแสดง Login/Register Form อัตโนมัติ)

ขั้นตอนที่ 1: เพิ่ม Script

เพิ่มโค้ดนี้ก่อนปิด </body> tag:

<!-- Socket.io for real-time (optional) -->
<script src="https://cdn.socket.io/4.8.1/socket.io.min.js"></script>

<!-- AG Chat Widget -->
<script src="https://meetanggroup.com/chat-widget.js"></script>
<script>
  AGChat.init({
    widgetKey: 'YOUR_WIDGET_KEY',
    apiUrl: 'https://meetanggroup.com'
  });
</script>

ขั้นตอนที่ 2: ผู้ใช้ลงทะเบียนหรือเข้าสู่ระบบ

ผู้ใช้จะต้องลงทะเบียนหรือเข้าสู่ระบบก่อนใช้งานแชท:

<!-- Widget จะแสดง Login/Register Form อัตโนมัติ -->
<script>
  AGChat.init({
    widgetKey: 'YOUR_WIDGET_KEY',
    apiUrl: 'https://meetanggroup.com'
    // ไม่ต้องส่ง customer - ผู้ใช้ต้อง login/register
  });
</script>

ขั้นตอนที่ 3: ทดสอบการใช้งาน

เมื่อผู้ใช้คลิกเปิด widget จะเห็น:

  • 📝 ฟอร์มลงทะเบียน: สำหรับผู้ใช้ใหม่ (ชื่อ, อีเมล, รหัสผ่าน)
  • 🔑 ฟอร์มเข้าสู่ระบบ: สำหรับผู้ใช้เดิม (อีเมล, รหัสผ่าน)
  • 💬 หน้าแชท: หลังจาก login สำเร็จ
✅ เสร็จแล้ว! Widget จะปรากฏที่มุมขวาล่างของเว็บไซต์

📚 API Reference

AGChat.init(config)

เริ่มต้นใช้งาน widget

AGChat.init({
  widgetKey: 'YOUR_WIDGET_KEY',  // Required: Widget key from admin panel
  apiUrl: 'https://meetanggroup.com'  // Required: Your API URL
  // Note: ผู้ใช้ต้อง login/register ผ่าน widget
});

AGChat.open()

เปิดหน้าต่างแชท

AGChat.open();

AGChat.close()

ปิดหน้าต่างแชท

AGChat.close();

AGChat.destroy()

ลบ widget ออกจากหน้าเว็บ

AGChat.destroy();

🔐 Authentication & Security

ระบบ Authentication ในตัว

Widget มีระบบจัดการผู้ใช้แบบบูรณาการ:

📝

การลงทะเบียน

ผู้ใช้สร้างบัญชีด้วยอีเมลและรหัสผ่าน

🔑

เข้าสู่ระบบ

Login ด้วยอีเมลและรหัสผ่านที่สมัครไว้

🔒

รหัสผ่านปลอดภัย

รหัสผ่านถูก hash ด้วย bcrypt

🎫

JWT Token

ใช้ JWT สำหรับ session management

Widget Key Management

สร้าง Widget Key ในหน้า Admin Panel:

1. ไปที่ Admin Panel → Widget Keys
2. คลิก "สร้าง Widget Key ใหม่"
3. ตั้งชื่อและกำหนด domain ที่อนุญาต
4. Copy Widget Key ไปใช้ใน AGChat.init()
🔒 Security: Widget Key จะถูก validate ทุกครั้งที่มีการเรียก API และสามารถปิดการใช้งานได้ทันทีจาก Admin Panel
